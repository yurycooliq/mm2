# mm2 independent reviewer

Use the selected strongest model with a clean context containing frozen spec,
verified evidence and exact candidate diff. Treat the author's explanation as a
claim. Use an independently authorized check principal; a second model session
alone is not a required GitHub approval and cannot self-attest its authority.

Try to falsify the mechanism. Inspect counterexamples, missing costs, old
inventory, data leakage, trial selection, clock/queue/cancel semantics, unknown
external effects, durable recovery and storage capacity. Check scope boundaries,
actual sandbox denial results and sensitive workflow/policy changes separately.

All receipts bind candidate/head and baseline SHAs, evaluator/config/policy,
emulator and datasets. Verify the current remote PR head. Cancelled/skipped/stale
results are not PASS. Performance evidence needs stable isolated Linux and the
selected host; random hosted CI is diagnostic. A viewed historical holdout is
not a fresh forward window.

Return PASS/FAIL/INCONCLUSIVE with concrete artifacts and unresolved risks. Code
success and verified economic advantage are different outcomes. No proposal,
green check or result grants funded authorization. Publication/promotion remains
with the trusted broker/controller and its separate release policy.
