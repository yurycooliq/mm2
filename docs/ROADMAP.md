# Delivery and evidence gates

## Implemented local work

- Independent repository, Rust workspace, fixed-point lifecycle core and deterministic exchange emulator.
- Shared bounded golden tapes and isolated TypeScript oracle for five execution scenarios.
- Owner API, authenticated idempotent CAS commands, durable execution replay, crash recovery and local process fence.
- Separate Telegram/SQLite operator process and React/Vite Mini App with real local state/controls.
- Public feed adapters, bounded historical importer, archive quality validator and host-comparison tools.
- Pinned Docker bases, Compose runtime boundaries, local/container tests and CI.

## Remaining economic evidence

Acquire a small complete development set from Pendulumflow with pinned market identities, manifests and hashes. The previously acquired September 29 development window had unresolved complementary-book/equal-clock reconstruction disagreements and is not a scoring set. A successful download is not a valid book or holdout.

Acquire authorized historical governing TWAP60 reports and verify identity, publication/receive availability, boundaries and settlement labels. Binance spot is only diagnostic reference and must not replace the governing settlement stream. Freeze the candidate, parameters, fees, dataset and acceptance criteria before a new untouched holdout. Run conservative queue and latency cases; report exclusions, finite capital, worst days and exposure. Synthetic emulator tapes cannot establish return.

## Remaining exchange application code

Pin and integrate the official Rust SDK behind a gateway after core/strategy contracts are stable. Resolve the actual owner/signing/funder wallet, deployed exchange protocol, asset identifier and collateral together. Add signer capacity scheduling with reserved cancel tokens, deadlines, request expiry, per-batch outcomes, authenticated user streams and account reconciliation. Persist a submission intent before an authenticated money-moving request; unknown responses must not free reservations or cause duplicate orders.

The current emulator's transport and fault contracts supply local tests for that gateway; they are not the exchange's authenticated endpoint implementation. Add sell, fees, settlement, merge/redemption and keyed multi-market inventory before applying a strategy that requires them.

## Selected-host verification

AWS registration is deferred. Once an eligible host is selected, repeat public TLS/WSS readiness, clock bounds, simultaneous CLOB/reference arrival comparisons, durability/recovery under resource limits and end-to-end latency tracing. Public HTTP latency does not measure cancel arrival at the matching engine. Direct London co-location needs the documented access route; do not infer eligibility from server IP alone.

Set HTTPS ingress and the exact Mini App origin, configure the owner's Telegram bot locally and test signed owner access. No hosting, registry publication, live Telegram traffic or funded orders is required to validate the offline package.

## Real execution gate

Before any funded canary, obtain the owner's explicit real-order authorization and preset wallet, capital, markets, loss/exposure limits and stop conditions. Confirm account/journal parity and actual fills/costs against the conservative model. `live_eligible` stays false throughout current local and public-shadow modes. No monthly income estimate is attached to this repository.
